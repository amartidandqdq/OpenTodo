## Why
On a phone, list header actions compete with the task list for attention. Keep the primary task flow clear while retaining the available tools.

## What Changes
- Move Inbox processing and duration filtering into the mobile list overflow menu.
- Keep an active duration filter visible and removable in the header.
- Keep the floating add button visible while scrolling on a phone.
- Place task source information below the title on phone rows.

## Capabilities
### Modified Capabilities
- `task-list-presentation`: simplify mobile list actions.

## Impact
- Mobile list headers only; no data or server changes.
