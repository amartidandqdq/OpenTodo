# Design

## D1. Reuse the dossier follow-up write

The card calls `setDossierFollowUp(dossierId, date)`, the function the dossier
page already used. It refuses a date when the dossier is not on hold and writes
one `dossier` patch. No new op, field or schema change.

## D2. The card decides editability from the caller's `canEdit`

`DossierCard` takes an optional `canEdit(task)`. A waiting thread's date is
editable when there is no `canEdit`, when the thread has no live step yet, or
when at least one live step is editable. The callers that show threads
(Reprendre le fil, Ma journée, Waiting, the dossier page) pass the same
`canEdit` that `useDossierData` builds from the cached memberships, so the card
and the step rows agree. Otherwise the card shows the date as text, as before.

The dossier's own text being undecryptable does not block the date: the date is
not encrypted content.

## D3. One editor per screen

The dossier page rendered its own follow-up field inside the hold block. It is
removed; the card renders the field and carries `data-dossier-follow-up`, so the
existing test and the page keep one editor. The hold dialog still asks for the
date when the thread is put on hold.

## D4. Copy only for the keep action

The capture offer keeps its close control and Escape behaviour. Only the visible
label of the keep action changes, to the reference's wording. Its test hook
(`data-dossier-link-keep`) is unchanged.

## D5. Translations

Three new messages (`Look again on`, `Follow-up date, no due date on the task.`,
`Keep as a separate task`) and the retired `Keep as a task` are reflected in
`web/src/locales/fr.json`, generated by `scripts/i18n/extract.mjs --write` and
checked by `scripts/i18n-check.mjs`. Other catalogues are not touched here.

## D6. Dependency on resume-dossiers

The `MODIFIED` requirement names a requirement of the `task-dossiers` capability
that the unarchived `resume-dossiers` change introduces. Archive
`resume-dossiers` before archiving this change; `openspec validate` reports the
target as missing until then (informational, the change itself is valid).
